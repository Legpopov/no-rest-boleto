# no-rest-boleto

Открытые рыночные цены на поездки из Москвы: авиабилеты туда-обратно, поезда, автобусы и отели
по 244 городам России и мира. Каждую ночь сборщик обновляет `data/prices.json`; по этим данным
работают сайт и Excel-макрос.

**Сайт: https://no-rest-boleto.pages.dev/**
(запасной адрес на Netlify: https://norestboleto.netlify.app/ — обновляется реже)

## Что умеет сайт

- **Города** — таблица цен по всем городам: авиа (медиана и 90-й перцентиль), поезд, отель за ночь.
  Дата снимка видна в шапке.
- **Авиа** — поиск билетов на конкретные даты со ссылкой на покупку в Aviasales и подсказкой
  гибких дат: «если вылететь на день раньше — дешевле на …», календарь цен ±3 дня.
- **Поезда** — расписание и цены по классам вагонов (сидячий, плацкарт, купе, СВ, люкс),
  ссылки на покупку на РЖД и tutu.ru на выбранные даты.
- **Отели** — карта (OpenStreetMap) с фильтрами по звёздам, рейтингу, расстоянию до центра, цене
  и типу размещения; ссылки на Островок, Яндекс Путешествия и Booking на ваши даты.
- **Итог** — оценка стоимости поездки: дорога + отель × число ночей.

Работает на телефоне. Все цены ориентировочные (кэш поисков и цены «от»), не оферта —
перед покупкой проверяйте по ссылкам.

## Источники данных

### Покрытие планового калькулятора Excel

География отправления расширена с восьми городов до **50 городов официального
списка филиалов Академии, включая Москву**. Источник списка и дата его получения
сохранены в `data/planning-cities.json`: [Филиалы Академии](https://www.ranepa.ru/filialy/).
Назначение не ограничивается филиалами: каталог расширяется городами, которые
вернул источник авиа и удалось однозначно сопоставить с официальным справочником
Travelpayouts. Соседний аэропорт автоматически не подставляется.

Снимок 11 ноября 2026 года: **1 603 города, 51 063 расчётные записи**.
Авиа: 41 843 односторонних ориентира кэша, 11 749 направленных пар с ценой хотя бы
на один месяц. Из них 1 086 пар имеют все месяцы февраля–июня, 711 — все месяцы
сентября–января. Это наличие базовых месяцев, не гарантия наличия билетов.
Исторические 881 сопоставимый ориентир АТОР сохранены как отдельный резерв.
ЖД/автобус: проверены 288 комбинаций направление/вид; цены есть на 118
направлениях ЖД и 59 автобусных. Новая наземная выборка охватывает филиалы
в обоих направлениях с Москвой и прежнюю сетку восьми городов; остальные
наземные пары пока не проверены. Сборщик принимает произвольные направления
из справочника, но их наличие в списке само по себе не создаёт цены.

Хотя бы одна исходящая цена есть для **46 из 50** городов отправления.
Для Донецка, Красноармейска, Красногорска и Ясиноватой подходящий свежий тариф
в этой проверке не получен. Это не утверждение об отсутствии сообщения.
Подробный отчёт: `data/planning-coverage.json`.

| Вид | Основа расчёта | Индексация и ограничения |
|---|---|---|
| Авиа | Текущие односторонние минимумы кэша Aviasales по месяцу, включая варианты с пересадками; при нехватке — сопоставимый АТОР | Фактический год вылета сохраняется. Состав багажа кэш не сообщает: при ДА применяется явно заданная надбавка книги за одно направление |
| Поезд | Средние цен «от» по поездам/классам с весами по числу цен | Классы и фирменность выбирает книга. Сезонность пока не оценена |
| Автобус | Средние ориентиров Туту; резерв Атласа с проверкой направления и RUB | Минимумы по датам не смешиваются с недатированными low/high. Сезонность пока не оценена |
| Проживание | Среднее текущих предложений Островка после фильтров книги | Учитываются ночи и календарные месяцы семестра; нормативные лимиты не индексируются |

Для подходящих направлений внутри РФ используется **сценарий на основе
общего индекса пассажирского транспорта Росстата**, а для проживания — индекса
гостиниц и прочих мест проживания: сентябрь 2026 к сентябрю 2025,
соответственно **111,89%** и **105,87%**.
[Первичная публикация](https://www.rosstat.gov.ru/storage/mediabank/157_09-10-2026.html).
Проверен полный индексированный текст таблицы и её заголовки; прямой HTML
не скачался из-за ошибки сертификата. Способ получения записан в
`data/planning-indices.json`.

Это наблюдённые индексы широких категорий, **не индексы отдельного маршрута,
вида транспорта или города и не официальный прогноз**. Их ежегодное повторение
в будущем остаётся сценарным допущением. Российские индексы не переносятся на
зарубежные направления и территории, исключённые из публикации: там сохраняется
явно подписанный макросценарий RUB 4% по
[прогнозу ЦБ](https://www.cbr.ru/dkp/mp_dec/decision_key_rate/comment_05112026/).
Курс и местные зарубежные цены отдельно не прогнозируются; после 2029 года
макросценарий экстраполируется. Количественная точность не установлена.

#### Что будет при отправлении из другого города?

Например, Воронеж → Москва теперь имеет отдельные железнодорожные и автобусные
ориентиры. Возврат рассчитывается по своему направлению, без зеркального копирования.
Цепочка с любым числом явно введённых участков сохраняется; промежуточные города
не обязаны иметь филиал. Кэш авиа может уже содержать сквозной перелёт с пересадками:
его цена относится ко всему участку, её нельзя складывать повторно с его частями.
Подбор стыковок по времени и автоматическая маршрутизация всех видов не выполняются.

Если нужный город, вид или месяц не покрыт данными, J получает `#Н/Д`, а W —
причину. Ошибка передаётся в итоговый прогноз. Неопубликованная цена, ошибка
источника, неподтверждённая станция, 404 и сообщение об отсутствии прямого рейса
различаются. Нулевая цена, соседний город и усреднение неполного семестра
автоматически не подставляются. Новый семестровый каталог относится к Excel;
прежний городской обзор сайта по-прежнему использует свой московский сборщик.

### Допущение для исторических и плановых авиатарифов

Для направлений, представленных в мониторинге [АТОР — Ассоциации туроператоров
России](https://www.atorus.ru/about), используем опубликованные минимальные тарифы
на контрольные даты, обычно при покупке примерно за месяц до вылета.
АТОР — отраслевое объединение туроператоров, а не орган государственной статистики.

**Это плановый ориентир, а не средняя стоимость всех проданных билетов за месяц.**
Данные хранятся отдельно для каждого направления, даты вылета и наличия багажа;
односторонние тарифы не смешиваются с перелётами туда-обратно. Сравнение одинаковых
месяцев разных лет показывает динамику контрольных тарифов, а не официальный ИПЦ.
Исключения дат и несовпадение горизонта покупки требуют отдельной проверки.
Перенос этой динамики на будущие годы — сценарное допущение, не гарантированный
прогноз. Общий индекс выборки нельзя выдавать за индекс конкретного маршрута.

Покрытие неполное: отсутствующие направления, месяцы, ЖД и проживание не становятся
известными только благодаря мониторингу авиа. При нехватке данных сохраняется явный
статус; нулевая цена или нулевая инфляция автоматически не подставляются.
Извлечённые тарифы и сравнения: `data/research/`; методика и воспроизведение:
[docs/research-collection.md](docs/research-collection.md).

Набор подключён к семестровому расчёту Excel через `data/planning.json` и
`excel/modPlanning.bas`: происхождение тарифа и ограничения показаны рядом
с результатом. Пока сопоставимые пары покрывают отдельные авиа-направления
марта и мая–декабря; отчёт за все 24 месяца — `data/research/coverage.json`;
полный семестр при нехватке месяцев выдаёт явную ошибку неполного расчёта.
Сайт продолжает использовать текущие цены. Инструкция подключения и ограничения:
[excel/README.md](excel/README.md#семестровое-планирование).

| Данные | Источник |
|---|---|
| Авиабилеты | Aviasales Data API (Travelpayouts) — кэш поисков пользователей за последние дни |
| Поезда | Туту (через сервис Travelpayouts), цены «от» по классам вагонов |
| Автобусы | Атлас (atlasbus.ru) — для городов России без поезда |
| Отели | публичная выдача Островка |
| Курсы валют | ЦБ РФ |
| Координаты | Travelpayouts autocomplete, OpenStreetMap Nominatim |

Сбор идёт каждую ночь в 01:00 по Москве в GitHub Actions (`.github/workflows/collect.yml`).
Если источник в какую-то ночь не ответил, для города остаются прошлые данные с пометкой «устарело».

## Структура

Подробная матрица направлений, месяцев, источников и причин пробелов для
50 городов отправления описана в [проверке покрытия маршрутов](docs/route-coverage.md).
Показатели до и после расширения находятся в `data/route-coverage/summary.json`.
Полный семестр учитывается отдельно от наличия хотя бы одной цены.

```
collector/              сборщик (Python)
  cities.csv            список городов (порядок строк задаёт id c000, c001, …)
  codes.csv             коды станций «Экспресс» и адреса городов на Островке
  collect.py, merge.py  сбор и сборка data/prices.json
  sources/              модули источников
data/
  prices.json           цены по городам + курсы ЦБ + дата снимка (generated_at)
  hotels/<id>.json      список отелей города для карты
site/                   сайт: index.html, app.js, style.css (без сборки и фреймворков)
functions/api/          функции поиска для Cloudflare Pages (/api/flights, /api/trains)
netlify/
  lib/api.mjs           логика поиска — общая для Cloudflare и Netlify
  functions/            те же функции для Netlify
  build-data.mjs        запасная копия data/ внутрь сайта при сборке
  dev-server.mjs        локальный запуск сайта с функциями
excel/                  VBA-макрос «Обновить цены» для Excel (см. excel/README.md)
```

Сайт читает `prices.json`, отели и список городов прямо из этого репозитория
(raw.githubusercontent.com), поэтому новые данные появляются на сайте через несколько минут
после ночного коммита — без пересборки. Пересборка нужна только при изменении кода сайта.

## Развёртывание сайта (Cloudflare Pages)

Workers & Pages → Create → **Pages** → Connect to Git → этот репозиторий. Настройки:

| Параметр | Значение |
|---|---|
| Framework preset | None |
| Build command | `node netlify/build-data.mjs` |
| Build output directory | `site` |
| Root directory | пусто |
| Переменная окружения | `TRAVELPAYOUTS_TOKEN` (Encrypt) |

Именно **Pages**, а не Worker: Worker не подключает функции из `functions/`, и поиск авиа и поездов не заработает.
Netlify настроен через `netlify.toml` и пересобирается только при изменении кода сайта.

## Запуск локально

Сайт с функциями (токен берётся из `.env`):

```
node netlify/build-data.mjs
node netlify/dev-server.mjs 8888
```

Сборщик:

```
pip install -r requirements.txt
python -m collector.collect --cities "Казань,Сочи"
```

Ключи API передаются только через переменные окружения (`TRAVELPAYOUTS_TOKEN`) — в `.env` локально,
в секретах GitHub Actions и в настройках хостинга — и в репозиторий не попадают.
