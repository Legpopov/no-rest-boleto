# no-rest-boleto

Открытые рыночные цены на поездки из Москвы: авиабилеты туда-обратно, поезда, автобусы и отели
по 244 городам России и мира. Каждую ночь сборщик обновляет `data/prices.json`; по этим данным
работают сайт и Excel-макрос.

**Сайт: https://no-rest-boleto.pages.dev/**
(запасной адрес на Netlify: https://norestboleto.netlify.app/ — обновляется реже)

## Что умеет сайт

- **Города** — таблица цен по всем городам: авиа (медиана и 90-й перцентиль), поезд, отель за ночь.
  Дата снимка видна в шапке.
- **Авиа** — поиск билетов на конкретные даты со ссылкой на покупку в Aviasales и подсказкой
  гибких дат: «если вылететь на день раньше — дешевле на …», календарь цен ±3 дня.
- **Поезда** — расписание и цены по классам вагонов (сидячий, плацкарт, купе, СВ, люкс),
  ссылки на покупку на РЖД и tutu.ru на выбранные даты.
- **Отели** — карта (OpenStreetMap) с фильтрами по звёздам, рейтингу, расстоянию до центра, цене
  и типу размещения; ссылки на Островок, Яндекс Путешествия и Booking на ваши даты.
- **Итог** — оценка стоимости поездки: дорога + отель × число ночей.

Работает на телефоне. Все цены ориентировочные (кэш поисков и цены «от»), не оферта —
перед покупкой проверяйте по ссылкам.

## Источники данных

| Данные | Источник |
|---|---|
| Авиабилеты | Aviasales Data API (Travelpayouts) — кэш поисков пользователей за последние дни |
| Поезда | Туту (через сервис Travelpayouts), цены «от» по классам вагонов |
| Автобусы | Атлас (atlasbus.ru) — для городов России без поезда |
| Отели | публичная выдача Островка |
| Курсы валют | ЦБ РФ |
| Координаты | Travelpayouts autocomplete, OpenStreetMap Nominatim |

Сбор идёт каждую ночь в 01:00 по Москве в GitHub Actions (`.github/workflows/collect.yml`).
Если источник в какую-то ночь не ответил, для города остаются прошлые данные с пометкой «устарело».

## Структура

```
collector/              сборщик (Python)
  cities.csv            список городов (порядок строк задаёт id c000, c001, …)
  codes.csv             коды станций «Экспресс» и адреса городов на Островке
  collect.py, merge.py  сбор и сборка data/prices.json
  sources/              модули источников
data/
  prices.json           цены по городам + курсы ЦБ + дата снимка (generated_at)
  hotels/<id>.json      список отелей города для карты
site/                   сайт: index.html, app.js, style.css (без сборки и фреймворков)
functions/api/          функции поиска для Cloudflare Pages (/api/flights, /api/trains)
netlify/
  lib/api.mjs           логика поиска — общая для Cloudflare и Netlify
  functions/            те же функции для Netlify
  build-data.mjs        запасная копия data/ внутрь сайта при сборке
  dev-server.mjs        локальный запуск сайта с функциями
excel/                  VBA-макрос «Обновить цены» для Excel (см. excel/README.md)
```

Сайт читает `prices.json`, отели и список городов прямо из этого репозитория
(raw.githubusercontent.com), поэтому новые данные появляются на сайте через несколько минут
после ночного коммита — без пересборки. Пересборка нужна только при изменении кода сайта.

## Развёртывание сайта (Cloudflare Pages)

Workers & Pages → Create → **Pages** → Connect to Git → этот репозиторий. Настройки:

| Параметр | Значение |
|---|---|
| Framework preset | None |
| Build command | `node netlify/build-data.mjs` |
| Build output directory | `site` |
| Root directory | пусто |
| Переменная окружения | `TRAVELPAYOUTS_TOKEN` (Encrypt) |

Именно **Pages**, а не Worker: Worker не подключает функции из `functions/`, и поиск авиа и поездов не заработает.
Netlify настроен через `netlify.toml` и пересобирается только при изменении кода сайта.

## Запуск локально

Сайт с функциями (токен берётся из `.env`):

```
node netlify/build-data.mjs
node netlify/dev-server.mjs 8888
```

Сборщик:

```
pip install -r requirements.txt
python -m collector.collect --cities "Казань,Сочи"
```

Ключи API передаются только через переменные окружения (`TRAVELPAYOUTS_TOKEN`) — в `.env` локально,
в секретах GitHub Actions и в настройках хостинга — и в репозиторий не попадают.
