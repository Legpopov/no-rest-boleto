# Автоматический подбор для семестрового бюджета

В транспортной строке задаются отправление L, назначение F, предпочтения Q,
багаж R и прежние параметры семестра. J содержит сумму выбранных билетов,
умноженную на число поездок, V — транспорт по участкам, W — цепочку городов,
известные пересадки, методы оценки и предупреждения. Дата поездки необязательна.
S/T/U показывают путь только соответствующим видом транспорта; выбранный в J
путь может сочетать виды. Возвращение рассчитывается отдельно.

Приоритеты сравниваются последовательно: сначала избегается самый нежелательный
вид транспорта, затем следующий; после этого выбираются меньше пересадок и
меньшая сумма билетов. Повторение одного вида транспорта само по себе не
ухудшает его предпочтительность. Например, при порядке поезд → авиа → автобус
и обязательном автобусном последнем участке поезд до пересадки предпочтительнее
авиа. При одинаковых использованных видах выигрывает меньшее число пересадок.

Каждая граница отдельно оценённых билетов — одна пересадка. К ним добавляется
максимальное известное число внутренних авиапересадок в любом месяце семестра.
При известном итоге больше двух путь исключается. Неизвестное число внутренних
пересадок допускается с предупреждением **«лимит двух не проверен»**; при
сравнении используется известная нижняя граница, а не обещание нулевых пересадок.
Сквозной авиабилет считается одним ценовым участком, его плечи повторно не добавляются.

Для каждого участка необходима положительная цена во всех месяцах семестра.
Применяются существующие фильтры классов/фирменности ЖД, базового года и багажа.
Надбавка за багаж применяется один раз к каждому отдельно оцениваемому текущему
авиабилету. Обратные рёбра не создаются из прямых, циклы запрещены, отсутствующие
цены не заменяются нулями. Недостаток данных даёт #Н/Д и причину.

Это ценовой сценарий: расписание и достаточность времени стыковки не проверяются.
При пересадках W предупреждает, что сумма включает только билеты, без неизвестных
расходов на переезд между станциями/аэропортами и ночёвку. Эти расходы не объявляются
нулевыми. Данные по месяцам могут относиться к разным фактическим предложениям.

## Установка

Помимо прежних модулей импортировать `excel/clsPlanningRoutingEvents.cls` как
класс и `excel/modPlanningRouting.bas` как обычный модуль. Обновить
`modPlanning.bas` и `modPlanningCore.bas`, выполнить `RefreshPlanning` с новым
`data/planning-excel.json`, затем `InstallPlanning`.
Класс должен импортироваться из файла с CRLF. Проверки безопасности Excel не меняются.

Необязательный `transfer_counts` в каталоге схемы 3 содержит число внутренних
пересадок по порядку записей; null означает неизвестное значение. Старые каталоги
сохраняют поддержку: авиа без метаданных считается непроверенной. В книге карта
quote_id → число находится в AO:AP, имя `PlanningTransfers`; ширина основного
20-колоночного каталога не меняется. Граф используется повторно только в пределах
одного пересчёта при включённых событиях; изменения и AfterCalculate очищают его.
